# Critérios para verificar anulação de empenho — SOFi/CPE

## 1. Identificar o tipo do empenho (Lei 4.320/64, art. 60)
| Tipo | Quando se usa | Saldo normal? |
|---|---|---|
| Ordinário | valor certo, pago de uma vez (compra, diária) | NÃO: liquidou e pagou → sobra deve ser anulada |
| Estimativo (§2º) | valor incerto (Ticket, água, energia, encargos 39.26) | SIM durante o ano; no fim, sobra = anular |
| Global (§3º) | contrato com parcelas (limpeza, estagiários, internet) | SIM, desde que = parcelas que faltam no exercício |

## 2. Perguntas para cada empenho com saldo
1. Saldo > o que ainda falta executar até 31/12? (meses/quinzenas restantes × valor médio) → excesso = anular parcial
2. Último movimento (95 › 01) há mais de 60 dias? → cobrar o setor; > 90 dias → regra do Dec. 37.924/96
3. O contrato está vigente? Há entrega ou nota pendente? (fiscal/almoxarifado)
4. A fonte tem dinheiro para pagar até 31/12? (96 › 09) — 2026 é último ano de mandato: LRF art. 42
5. Vale virar Restos a Pagar? Só se a obrigação está em curso e com justificativa (decreto de encerramento)

## 3. Decisão
| Situação | Ação |
|---|---|
| Resíduo de centavos/reais após pagamento | anular |
| Ordinário pago com sobra | anular a sobra |
| Diária com saldo > 30 dias | pagar ou anular (missão cancelada?) |
| Estimativo/global com saldo maior que o necessário até 31/12 | anular parcial (devolve crédito/cota) |
| Saldo inteiro > 90 dias sem justificativa | consultar setor; sem previsão → anular |
| Entrega/serviço em andamento, com contrato vigente | manter (possível RPNP) |

## 4. Aplicação inicial (23/11/2026)
- Ticket 862 (PRF): saldo 1.413.219,02 × ~3 quinzenas restantes (~200 mil cada ≈ 600 mil) → possível excesso ~800 mil
- Ticket 718 (SEMAD): saldo 893.743,20 × ~3 quinzenas (~80 mil cada ≈ 240 mil) → possível excesso ~650 mil
- Ticket 716 (DER): 650.000,00 nunca usado (250 dias) → anular ou justificar
- Limpeza 863: saldo 16.768,71 = 1 parcela mensal → coerente; conferir 886, 983, 984 com o valor mensal de cada contrato

## Lição (23/11/2026)
- A data da 95 › 04 é a da EMISSÃO do empenho, não do último movimento. "Parado" só se confirma no extrato (95 › 01). Ex.: emp. 320 (Tática, fonte 60) emitido em 13/02, mas com liquidação mensal até 09/11.
